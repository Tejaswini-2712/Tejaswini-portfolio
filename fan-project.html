Automated Fan Control System

An automation project focused on controlling fan operation based on environmental conditions to support user comfort and energy efficiency.

Project Overview

The Automated Fan Control System aims to reduce the need for continuous manual fan control. Depending on the project's implemented design, sensors and a controller can be used to adjust fan operation according to the detected conditions.

Problem Statement

Manually operating a fan may lead to unnecessary energy use when cooling is not required. An automated approach can help make fan operation more convenient and efficient.

Project Objective

  • Explore automated fan control.
  • Improve convenience by reducing manual operation.
  • Support efficient use of electrical energy.
